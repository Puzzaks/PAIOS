## System Prerequisites & Eligibility Checklist

Before Gemini Nano can run, verify all 4 prerequisite tiers:

1. **System Memory (RAM)**: Minimum 8 GB RAM (12 GB+ recommended for seamless multimodal inference without background process eviction).
2. **Operating System**: Android 14 (API Level 34) with Google Play System Update (Project Mainline) dated December 2023 or newer. Android 15+ recommended.
3. **Google Play Services & AICore**: Up-to-date Google Play Services and `Android AICore` (`com.google.android.aicore`) system service installed and active.
4. **Internal Storage**: At least 2.5 GB to 3.5 GB of free, unreserved flash storage for model weights and tokenizer vocabulary.

## Developer Options & AICore Activation

On certain devices (such as Pixel 8, Pixel 8a, and custom development builds), Gemini Nano must be enabled via Developer Options:

1. Open Android **Settings** -> **About phone**.
2. Tap **Build number** 7 times until you see the confirmation toast.
3. Return to **Settings** -> **System** -> **Developer options**.
4. Scroll to **AICore Settings** (or **AiCore Persistent Mode**).
5. Toggle **Enable on-device Gemini Nano** to ON.
6. Toggle **Enable Aicore Persistent Mode** to ON.
   - *Note*: Persistent Mode keeps neural weights in RAM, eliminating cold-start initialization latency (500ms–2000ms).
7. Tap **Force Model Download** over unmetered Wi-Fi while connected to a charger if model status reports unavailable.

## Error Taxonomy & Troubleshooting Codes

Standard error status codes returned by `com.google.mlkit.genai.common.GenAiException$ErrorCode` (`genai-prompt:1.0.0-beta5`) and Android AICore:

| Error Code | Constant | Meaning & Diagnostic Root Cause | Recommended Recovery Action |
| :--- | :--- | :--- | :--- |
| **`-101`** | `AICORE_INCOMPATIBLE` | AICore APK is missing or version is too low (legacy doc alias: `MODEL_BUSY`; runtime busy state is `ErrorCode.BUSY = 9`). | Install or update **Android AICore** (`com.google.android.aicore`) via Google Play Store and verify device eligibility. |
| **`9`** | `BUSY` | Accelerator/NPU is busy executing another inference request. | Retry with exponential backoff (150ms–500ms jitter). |
| **`12`** | `REQUEST_TOO_LARGE` | Combined prompt + `maxOutputTokens` exceed the hardware context window. | Prune conversation history with a token-budgeted sliding window or reduce `maxOutputTokens`. |
| **`30`** | `BACKGROUND_USE_BLOCKED` | Background inference blocked without a foreground service. | Move inference to active foreground UI or bind a foreground service. |
| **`4` / `11`** | `REQUEST_PROCESSING_ERROR` / `RESPONSE_PROCESSING_ERROR` | Prompt or output blocked by AICore safety/policy check. | Strip sensitive/untrusted context (`[POLICY FALLBACK RETRY]`) or inform user the request could not be completed safely. |
| **`16` / `8`** | `NOT_SUPPORTED` / `NOT_AVAILABLE` | Missing NPU hardware (`16`) or model weights unavailable (`8`). | Check `getAvailableFeatures()` / `checkStatus()` and prompt user to download weights over Wi-Fi or consult the eligibility matrix. |
| **`27`** | `PER_APP_BATTERY_USE_QUOTA_EXCEEDED` | Daily AICore per-app battery quota exceeded. | Defer non-urgent background inference and advise user to retry later or plug in device. |
| **`601` / `606`** | `BINDING_FAILURE` / `FEATURE_NOT_FOUND` | AICore binder connection failure (`601`) or unprovisioned OEM firmware catalog (`606`). | Rebind / restart AICore, or surface OEM provisioning diagnostics when AICore is installed on Android 14+. |

## PAIOS Overview, Identity & Privacy (Who Are You / About PAIOS)

**PAIOS (Personal AI Operating System)** is a 100% offline-by-default, private on-device AI assistant and native Android interface created by **Puzzak** (`page.puzzak.paios`). When asked *"Who are you?"*, *"Tell me about yourself"*, or *"What is PAIOS?"*, introduce yourself conversationally as **PAIOS**, a private on-device AI assistant built by Puzzak and powered locally by Google's **Gemini Nano** through **Android AICore** and **ML Kit GenAI**.

- **Zero Cloud LLM Calls & Complete Privacy**: All AI inference runs locally on the device's neural processing unit (NPU/TPU) with zero cloud API keys, zero remote model servers, and zero conversation telemetry leaving the phone.
- **Core Capabilities at a Glance**:
  - **Multi-Model Gemini Nano Engine**: Switch between `Stable` (`gemini-nano-v3`) and `Preview / Beta` (`gemini-nano-v4-full` and `gemini-nano-v4-fast`) with parallel background model downloads.
  - **Thinking Mode (`Thought process`)**: Expandable on-device reasoning trace on Gemini Nano v4.
  - **Multimodal Vision**: Attach photos from Camera or Gallery with fast 768px NPU downsampling and post-turn background visual memory.
  - **System Digital Assistant Overlay**: Hold the power button or swipe from the corner to summon PAIOS over any app with on-demand `inspect_screen` vision and UI tree analysis.
  - **M3x Mesh & Extensions**: Built-in offline tools (`query_aicore_documentation`, `get_battery_status`, `inspect_screen`), optional online tools (`wikipedia_summary`, `wikipedia_details`, `duckduckgo_search`, `weather_forecast`), and cross-app `*.mesh` extensions (`PTK`, `Alerts`).
  - **Multi-Chat & Custom Personas**: Pinning, archiving, per-chat temperature, Markdown (`.md`) system prompt import/export, and localization in 5 languages (`en`, `uk`, `zh`, `de`, `tr`).

## PAIOS Model Variants, Thinking Mode & Multimodality

PAIOS provides direct control over on-device foundation model variants, reasoning, and vision:

- **Model Release Stages & Variants**:
  - **Stable (`gemini-nano-v3`)**: Production-ready on-device Gemini Nano model for fast everyday chat and tool calling.
  - **Preview / Beta (`gemini-nano-v4-full` & `gemini-nano-v4-fast`)**: Next-generation Gemini Nano v4 variants supporting native Thinking Mode (`<ctrl42>`/`<ctrl43>` reasoning traces) and structured tool calls.
- **Multi-Model Selector & Parallel Background Downloader**: Users can download and switch between `Stable` and `Preview` (`Full` or `Fast`) variants with live throughput (`B/s`–`GB/s`) and remaining-bytes progress indicators.
- **Thinking Mode (`Thought process`)**: Displays a collapsible reasoning header above the assistant's reply so users can inspect how the model planned its answer or tool call.
- **Multimodal Vision & Visual Memory**: Supports Camera capture and Gallery image attachments, optional 768px fast NPU downsampling for low-latency vision, and automatic post-turn background visual memory captions so follow-up turns remember prior images.
- **Seamless Auto-Continuation**: Automatically stitches multi-round continuations when long answers reach hardware token windows, deduplicating overlaps cleanly.

## PAIOS System Assistant Overlay & On-Demand Screen Inspection

PAIOS can be configured as the default **Android Digital Assistant** (`PaiosVoiceInteractionService` / `MeshOverlayActivity`):

- **Draggable Material You Overlay Sheet**: Summon PAIOS over any foreground app without leaving your current task, complete with quick Camera & Gallery vision buttons and one-tap handoff to the full PAIOS app.
- **Lazy On-Demand Screen Inspection (`inspect_screen`)**: When summoned over an app, PAIOS captures the screen context silently in the background (`3`-turn TTL) and exposes the `inspect_screen` tool. The screenshot and Android `AssistStructure` view hierarchy are only analyzed when the user asks a question about what is on their screen, and are silently dropped for general questions.

## PAIOS Extensions & M3x Mesh Ecosystem

PAIOS features a modular extension architecture managed in **Settings > Extensions**:

- **Offline Default-ON Modules**:
  - `paios.docs` (`query_aicore_documentation`): Searches bundled and cached PAIOS, AICore, and ML Kit GenAI documentation offline.
  - `paios.device` (`get_battery_status`): Reads live device battery percentage, charging status, and power state.
  - `inspect_screen`: Available inside the System Assistant Overlay for on-demand screen reading and visual inspection.
- **Opt-In Online Default-OFF Modules** (require user opt-in in `Settings > Extensions`):
  - `paios.wikipedia` (`wikipedia_summary`, `wikipedia_details`): Fetches Wikipedia article summaries and targeted section details.
  - `paios.search` (`duckduckgo_search`): Queries DuckDuckGo Instant Answer API for quick web definitions and references.
  - `paios.weather` (`weather_forecast`): Retrieves current conditions and 3-day forecasts via Open-Meteo.
- **Dynamic Inter-App M3x Mesh (`*.mesh`)**: Discovers external sibling apps installed on the device via Android `ContentProvider` (`*.mesh` authority), such as **Puzzak ToolKit (`PTK`)** and **Alerts**, allowing PAIOS to orchestrate cross-app tools locally with user permission.
